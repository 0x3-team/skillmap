# T0.04 — macOS-safe isolated-run recipe

This is a design-only runbook for two **separate** later tasks. It was not executed while preparing this document. Its purpose is to preserve the current dirty working tree exactly, run the approved install and root test only in a fresh temporary copy, and write one redacted evidence artifact only after the source has been proven stable.

The approved downstream runtime is `<home>/.local/bin/node` `v22.23.1` and `<home>/.local/bin/npm` `10.9.8`. T0.02 establishes the exact commands (`npm ci`, then `npm test`); T0.03 establishes that the root test script builds first and launches `scripts/run-root-tests.mjs` with its current process executable.

## Authorization and inputs

Run this only in the separately dispatched task named in the first column. Copy the task and dispatch identifiers from that task's Orca dispatch; do not reuse any identifier from T0.04 or a previous run.

| Later task | `RUN_LABEL` | required `EVIDENCE_OUTPUT` | temp basename prefix | gate |
| --- | --- | --- | --- | --- |
| T0.05 | `T0.05` | `docs/plans/evidence/T0.05-isolated-root-run-a.json` | `skillmap-t0.05.` | T0.04 approved |
| T0.06 | `T0.06` | `docs/plans/evidence/T0.06-isolated-root-run-b.json` | `skillmap-t0.06.` | a **new** T0.06 dispatch after the coordinator has reviewed and approved T0.05 |

The executor supplies these five inputs as environment variables for one shell session. They are deliberately required rather than defaulted, so a small model cannot accidentally carry an old task identity into a new receipt.

| Input | Rule |
| --- | --- |
| `TASK_ID` | exact nonempty `task_…` identifier from the active T0.05 or T0.06 dispatch |
| `DISPATCH_ID` | exact nonempty `ctx_…` identifier from that same dispatch |
| `RUN_LABEL` | exactly `T0.05` or `T0.06`; execute only one value per invocation |
| `EVIDENCE_OUTPUT` | exact table value for that label, repo-relative, and absent before finalization |
| `SOURCE_ROOT` | absolute path to the active skillmap worktree; it is read only until the final `apply_patch` artifact write |

Do not set `HOME`, `PATH`, or `CODEX_HOME`. Do not use a clean checkout, `git archive`, `/tmp` literal checks, `rsync`/`openrsync`, `tar`, `shasum`, or `date` timing. In particular, the locally available openrsync 2.6.9 lacks the needed NUL-list option; the bounded Node helper below consumes the NUL list itself.

## Invocation gate

Use this form only after the appropriate coordinator approval. The values in angle brackets are not literals: replace them only with the active later-task dispatch values.

```sh

# Do not begin T0.06 while this run or its review is pending.
export TASK_ID='<active T0.05 task id>'
export DISPATCH_ID='<active T0.05 dispatch id>'
export RUN_LABEL='T0.05'
export EVIDENCE_OUTPUT='docs/plans/evidence/T0.05-isolated-root-run-a.json'

```

This block binds inputs in the already-authorized later-task shell; it does not run the recipe by itself. Execute the ordered blocks below only for that label. Do not launch both labels in a loop or in parallel.

T0.06 is a fresh, later invocation only after coordinator approval of T0.05, and must be bound in a separate approved T0.06 shell before running this recipe.

## Ordered recipe for one later task

### 2. Write the bounded copy/hash/receipt helper below the run root

Create this file exactly at `$RUN_ROOT_CANON/helpers/isolated-run.mjs`. It accepts NUL-delimited paths, rejects absolute/traversal paths and every symlink, copies files through `O_NOFOLLOW`, preserves file mode, and emits deterministic JSON. It intentionally supports a missing captured path so a pre-existing tracked deletion is represented rather than silently restored; any source change after capture is still caught by the status and content checks.

```sh
HELPER="$RUN_ROOT_CANON/helpers/isolated-run.mjs"
[ ! -e "$HELPER" ] && [ ! -L "$HELPER" ] || {
  echo 'Helper target must not already exist or be symlinked.' >&2; exit 1;
}
printf 'Authorized temporary helper target: %s\n' "$HELPER"
```

Stop at this point and use `apply_patch` to add the following exact contents at the printed absolute helper path. Do not use `cat`, redirection, or another shell write to create it.

```js
  const [output, started, ended, exitCode, ran] = args;
  const didRun = parseBoolean(ran);
  if (!didRun) {
    if (started !== 'null' || ended !== 'null' || exitCode !== 'null') {
      die('run-meta expected null timing metadata when did-run is false.');
    }
    writeJson(output, { ran: false, exit_code: null, started_at_ms: null, ended_at_ms: null, duration_ms: null });
  } else {
    const start = asNonNegativeInteger(started);
    const end = asNonNegativeInteger(ended);
    const exit = asNonNegativeInteger(exitCode);
    if (end < start) die('run-meta requires nondecreasing timestamps.');
    writeJson(output, { ran: true, exit_code: exit, started_at_ms: start, ended_at_ms: end, duration_ms: end - start });
  }
}
else if (command === 'tap') {
  const [log, ran, output] = args;
  writeJson(output, parseTap(log, parseBoolean(ran)));
}
else if (command === 'receipt') {
  const [headFile, statusFile, sourceBeforeFile, destinationFile, stableFile, installFile, testFile, tapFile, installLog, testLog, output, sourceRoot, homeRoot, runRoot] = args;
  const head = readText(headFile);
  if (!/^[0-9a-f]{40,64}$/.test(head)) die('HEAD is not a full hexadecimal object id.');
  const status = readJson(statusFile);
  const sourceBefore = readJson(sourceBeforeFile);
  const destination = readJson(destinationFile);
  const stable = readJson(stableFile);
  const install = readJson(installFile);
  const test = readJson(testFile);
  const tap = readJson(tapFile);
  if (!sameSnapshot(sourceBefore, destination) || stable.source_stable !== true) die('Receipt requires completed copy and source-stability proof.');
  const receipt = {
    schema_version: 1,
    plan_key: process.env.RUN_LABEL,
    task_id: process.env.TASK_ID,
    dispatch_id: process.env.DISPATCH_ID,
    run_label: process.env.RUN_LABEL,
    temp_label: process.env.RUN_BASENAME,
    source_snapshot: {
      head,
      status_sha256: status.sha256,
      path_count: sourceBefore.path_count,
      content_and_mode_sha256: sourceBefore.content_and_mode_sha256,
      destination_match_verified: true,
      source_stability_verified: true
    },
    toolchain: {
      node_reference: '<home>/.local/bin/node',
      node_version: process.env.NODE_VERSION,
      npm_reference: '<home>/.local/bin/npm',
      npm_version: process.env.NPM_VERSION
    },
    commands: { install: 'npm ci', test: 'npm test' },
    environment: normalizedEnvironment(),
    install,
    test,
    tap_summary: tap,
    first_causal_error: firstCausalError(install.exit_code, test.exit_code, installLog, testLog, [sourceRoot, homeRoot, runRoot]),
    logs_retained: false
  };
  writeJson(output, receipt);
}
else if (command === 'validate-receipt') {
  const [file, sourceRoot, homeRoot, runRoot] = args;
  assertReceipt(file, [sourceRoot, homeRoot, runRoot]);
}
else if (command === 'assert-artifact-delta') {
  const [beforeFile, afterFile, evidencePath] = args;
  assertArtifactDelta(beforeFile, afterFile, evidencePath);
}
else if (command === 'assert-draft-artifact-match') {
  const [draftFile, artifactFile, output] = args;
  assertDraftArtifactMatch(draftFile, artifactFile, output);
}
else die('Unknown helper command.');
```

After `apply_patch` succeeds, validate the helper path and make only that temporary file executable:

```sh
}
```

### 3. Capture the exact dirty snapshot, hash it, and copy it

These commands use `GIT_OPTIONAL_LOCKS=0` for every source Git read. The raw NUL status file is digested as bytes; tracked plus non-ignored untracked names are independently captured, then combined in the temporary tree. The snapshot hash includes each sorted path, entry kind, executable mode, and SHA-256 of file contents.

```sh

GIT_OPTIONAL_LOCKS=0 git -C "$SOURCE_ROOT_CANON" status --porcelain=v1 -z --untracked-files=all > "$RUN_ROOT_CANON/capture/status-before.z"
GIT_OPTIONAL_LOCKS=0 git -C "$SOURCE_ROOT_CANON" ls-files -z > "$RUN_ROOT_CANON/capture/tracked.z"
GIT_OPTIONAL_LOCKS=0 git -C "$SOURCE_ROOT_CANON" ls-files --others --exclude-standard -z > "$RUN_ROOT_CANON/capture/untracked.z"
"$NODE_BIN" "$HELPER" file-digest "$RUN_ROOT_CANON/capture/status-before.z" "$RUN_ROOT_CANON/capture/status-before.json"
"$NODE_BIN" "$HELPER" combine "$RUN_ROOT_CANON/capture/tracked.z" "$RUN_ROOT_CANON/capture/untracked.z" "$RUN_ROOT_CANON/capture/paths.z"
"$NODE_BIN" "$HELPER" hash "$SOURCE_ROOT_CANON" "$RUN_ROOT_CANON/capture/paths.z" "$RUN_ROOT_CANON/capture/source-before.json"

"$NODE_BIN" "$HELPER" copy "$SOURCE_ROOT_CANON" "$ISOLATED_SOURCE" "$RUN_ROOT_CANON/capture/paths.z"
[ ! -e "$ISOLATED_SOURCE/.git" ] && [ ! -e "$ISOLATED_SOURCE/node_modules" ] || {
  echo 'Isolated copy unexpectedly contains Git metadata or node_modules.' >&2; exit 1;
}
"$NODE_BIN" "$HELPER" hash "$ISOLATED_SOURCE" "$RUN_ROOT_CANON/capture/paths.z" "$RUN_ROOT_CANON/capture/destination.json"
"$NODE_BIN" "$HELPER" assert-snapshot-match \
  "$RUN_ROOT_CANON/capture/source-before.json" \
  "$RUN_ROOT_CANON/capture/destination.json" \
  "$RUN_ROOT_CANON/capture/copy-proof.json"

# Re-hash the source immediately after copying; any concurrent change aborts before install.
GIT_OPTIONAL_LOCKS=0 git -C "$SOURCE_ROOT_CANON" status --porcelain=v1 -z --untracked-files=all > "$RUN_ROOT_CANON/capture/status-after-copy.z"
"$NODE_BIN" "$HELPER" file-digest "$RUN_ROOT_CANON/capture/status-after-copy.z" "$RUN_ROOT_CANON/capture/status-after-copy.json"
"$NODE_BIN" "$HELPER" hash "$SOURCE_ROOT_CANON" "$RUN_ROOT_CANON/capture/paths.z" "$RUN_ROOT_CANON/capture/source-after-copy.json"
"$NODE_BIN" "$HELPER" assert-source-stable \
  "$RUN_ROOT_CANON/capture/status-before.json" \

  "$RUN_ROOT_CANON/capture/source-before.json" \
  "$RUN_ROOT_CANON/capture/source-after-copy.json" \
  "$RUN_ROOT_CANON/capture/source-after-copy-proof.json"
```

If any preflight, path, symlink, copy, source/destination digest, or after-copy stability assertion fails, stop immediately. Do not install, test, write an artifact, or clean up automatically; leave the isolated root for diagnosis and use the guarded cleanup only after the coordinator decides it is safe.

### 4. Run the exact install and test only in the isolated source

The approved Node supplies `Date.now()` for every millisecond timestamp. The npm shebang receives an explicitly command-scoped PATH with the approved Node directory first; the global `PATH`, `HOME`, and `CODEX_HOME` are never changed. Logs are raw only inside the temporary tree.

```sh

  cd "$ISOLATED_SOURCE"

) > "$RUN_ROOT_CANON/logs/npm-ci.log" 2>&1

set -e
INSTALL_ENDED_MS="$("$NODE_BIN" "$HELPER" now)"
"$NODE_BIN" "$HELPER" run-meta "$RUN_ROOT_CANON/run/install.json" \
  "$INSTALL_STARTED_MS" "$INSTALL_ENDED_MS" "$INSTALL_EXIT" true

if [ "$INSTALL_EXIT" -eq 0 ]; then
  TEST_STARTED_MS="$("$NODE_BIN" "$HELPER" now)"

  (
    cd "$ISOLATED_SOURCE"
    PATH="$NPM_COMMAND_PATH" "$NPM_BIN" test
  ) > "$RUN_ROOT_CANON/logs/npm-test.log" 2>&1
```

`npm ci` and `npm test` are the only install/test commands and each runs from `$ISOLATED_SOURCE`.
