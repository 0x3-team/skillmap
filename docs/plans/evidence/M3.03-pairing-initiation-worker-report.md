## Design decisions
- Strict JSON parser is self-contained (no `jsonc-parser`); no web `package.json` mutation.
- Runtime relative imports use explicit `.ts` extensions (matches repo `rate-limit.ts` convention), enabling Node ESM testability.
- Proof signature verified in the Node service layer via `crypto.subtle`; the DB RPC validates bounds + persists + idempotency.
- Raw device/user codes are never stored — only SHA-256 digests (`pg_catalog.sha256`, no pgcrypto hard dependency).
- Contract generator intentionally NOT run: it mutates `src/**` (out of scope). Registered in manifest only.
