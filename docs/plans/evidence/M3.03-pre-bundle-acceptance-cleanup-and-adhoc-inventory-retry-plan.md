## 11. Exact FD-anchored macOS cleanup protocol

### 11.1 Threat and lease boundary

The protocol protects against symlinks, stale artifacts, accidental path substitution, cooperating concurrent SkillMap actors, and preexisting receipt collisions. It assumes all authorized actors run with the same euid and obey the same advisory lease. It does not claim protection from a hostile same-euid process that ignores `flock`, ptraces the process, or races names between the last identity check and `unlinkat`.

The kernel API removes the object currently bound to a directory entry name. It does **not** provide an “unlink this inode” primitive. Holding an fd keeps the inspected object accessible after unlink but does not make name deletion atomically inode-addressed. Therefore:

- the coordinator serializes every Stage 2/retry actor;
- every actor opens fixed P3 no-follow, validates it, takes `flock(LOCK_EX|LOCK_NB)`, and holds that fd until its durable phase receipt is complete;
- every mutating stage also exclusively precreates its result-receipt fd and locks it before mutation;
- the immediate name-to-held-fd dev/inode comparison and unlink happen without await, subprocess, log, output, filesystem write, or callback between them;
- any competing lease, name drift, metadata drift, unexpected link, or postcondition mismatch blocks.

If the environment cannot provide fixed-parent `openat`/`fstatat`/`unlinkat` semantics and nonblocking advisory locks, cleanup is `CLEANUP_BLOCKED_PLATFORM_PRIMITIVE_UNAVAILABLE`; no pathname-only fallback is allowed.

### 11.2 Frozen parent and leaf rules

The only temporary parent is canonical `/private/tmp`:

1. verify public `/tmp` resolves to `/private/tmp`;
2. open `/private/tmp` as `tmp_fd = open("/private/tmp", O_RDONLY|O_DIRECTORY|O_NOFOLLOW)`;
3. require directory, uid 0, sticky world-writable mode `01777`, one filesystem identity held for the stage;
4. preflight `fsync(tmp_fd)` before mutation; failure blocks before deletion;
5. keep `tmp_fd` open through deletion, postconditions, receipt finalization, and the post-mutation `fsync(tmp_fd)`.

The rendezvous leaf is the literal ASCII name:

`skillmap-m303-dp-keychain-adhoc-gate-v1.locator`
