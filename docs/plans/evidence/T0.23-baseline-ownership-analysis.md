# T0.23 Baseline ownership analysis

## Method

- Comparator reference: `apps/web/scripts/local-app-qa.mjs` (`createVisualGate`).
- First pass used `pixelmatch` with `threshold: 0.05`, `includeAA: false`, `alpha: 0.2`, `diffColor: [220, 38, 38]`, `diffColorAlt: [37, 99, 235]`.
- Geometry pass used an exact second `pixelmatch` invocation with `diffMask: true` and the same threshold/includeAA/alpha/color settings.
- `diffMask: true` yields an exact counted-pixel mask, and rows/columns touched, cluster count, and bounding boxes were derived from that mask only.
- Baseline and current images were pulled from `HEAD` via `git show HEAD:apps/web/tests/visual-baselines/local-app/chromium-linux/<name>.png` and local filesystem paths respectively.
- `diffRatio` is `changedPixels / (width × height)`.
