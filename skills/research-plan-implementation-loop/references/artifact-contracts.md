# Artifact Contracts

## Research Dossier

Produced by `verified-research`.

Must include:

- research contract
- executive findings
- claim ledger
- source notes
- contradictions and uncertainty
- actionable implications
- what not to use
- planning handoff
- verification gaps

## Planning Artifact

Produced by `planning-orchestrator`.

Must include:

- research dossier path
- confirmed claims and assumptions
- explicit non-goals
- prioritized phases
- task backlog
- acceptance criteria
- validation plan
- risks, dependencies, blockers
- implementation orchestrator handoff

## Implementation Ledger

Produced or updated by `implementation-orchestrator` when implementation is authorized.

Must include:

- source plan path
- selected slice
- changed files
- worker scopes
- tests/checks
- local/browser/live/deploy status
- blocked checks
- remaining risks
- next slice or stop condition

## Loop Ledger

The controller goal should track:

- mode
- research dossier path
- plan artifact path
- implementation authorization
- worker decisions
- background browser lane
- claim statuses
- handoff status
- validation status
- final verdict
